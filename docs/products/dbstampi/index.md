# DbStampi

DbStampi è un ecosistema software costituito da un insieme di strumenti dedicati alla gestione del magazzino stampi.

## Database
[Database](db\index.md) SQL Server (2012+)

## Applicazioni Web
 - [DbManager](dm\index.md): Applicazione web dedicata alla gestione del database. 
 - [API](api\index.md): API REST e WCF di supporto alle applicazioni client.

## Applicazioni Windows
 - [Servizi](ws\index.md): Operazioni schedulate ad orari prestabiliti.
 - [Agenti](wa\index.md): Applicazioni di supporto.
 - [Localizzazione Stampi](ml/index.md): Applicazione Windows dedicata alla tracciatura della movimentazione degli stampi.
